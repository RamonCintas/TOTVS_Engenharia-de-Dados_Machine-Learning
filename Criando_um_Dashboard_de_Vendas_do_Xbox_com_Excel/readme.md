# 📊 Dashboard de Vendas Xbox

## 📌 Sobre o Projeto

Projeto desenvolvido no Excel para análise de vendas de assinaturas Xbox, utilizando tabelas dinâmicas e dashboard interativo para responder perguntas de negócio.

Os dados analisados possuem assinaturas dos tipos:

- Monthly (Mensal)
- Quarterly (Trimestral)
- Annual (Anual)

---

# 🛠️ Ferramentas Utilizadas

- Microsoft Excel
- Tabelas Dinâmicas
- Segmentação de Dados
- Dashboard Interativo

---

# 📈 Perguntas de Negócio

## 1️⃣ Qual o faturamento total das assinaturas?

A análise foi realizada considerando os planos:

Pergunta de Negócio 1 - Qual faturamento Total de vendas de planos anuais (contendo todas as assinaturas agregadas)

Pergunta de Negócio 2 - Qual Faturamento Total de vendas de planos anuais, separado por auto renovação / não é por auto renovação


### Resultado encontrado para o plano Annual:

| Tipo | Valor |
|---|---|
| Annual | R$ 1.754,00 |

---

## 2️⃣ Qual o faturamento anual separado por auto renovação?

| Auto Renovação | Valor |
|---|---|
| No | R$ 217,00 |
| Yes | R$ 1.537,00 |
| **Total** | **R$ 1.754,00** |

## 3️⃣ Qual o total de vendas do EA Play?
| **Total** | **R$ 600,00** |

# 📊 Principais Resultados

- Planos anuais geraram R$ 1.754,00;
- Auto renovação representa a maior parte das vendas;
- O dashboard permite análise entre planos Monthly, Quarterly e Annual.
